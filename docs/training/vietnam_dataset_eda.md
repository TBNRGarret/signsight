# Dataset EDA

Use the [SupSign EDA/train guide](supsign_yolo11s_colab.md) and the two supported notebooks. The former Kaggle/Drive-specific notebook variants have been retired; their last versions remain in Git history. Generic YOLO/VOC/COCO readers and synthetic data-integrity tests remain in `training/data/audit.py` and `tests/test_dataset_eda.py`.

For a custom local dataset use the [local Vietnam CLI](local_vietnam_pipeline.md); no backend or personal database is needed. Keep original archives unchanged. Review labels and grouping before training.
